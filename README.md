# Spend Better

Spend Better is a local-first desktop budgeting app that helps users track expenses, preserve budget history, and understand spending trends over time.

**To Download**
Click on the latest release and follow the instructions.

**Features**
- **Local-first persistence:** budgets, categories, expenses, notes, and historical monthly budgets live in a local SQLite database and remain available after closing, updating, or reinstalling the app.
- **Budget history is preserved:** each month has its own budget records, so past charts don’t change when a user edits today’s budget.
- **Automatic monthly continuity:** new months can carry forward the most recent budget setup instead of making users re-enter every category.
- **Finance-safe storage:** money is stored as integer cents—not floating-point dollars—so calculations avoid precision issues.
- **Useful analytics:** overall variance, six-month trends, category-specific variance cards, averages that ignore inactive months, and interactive tooltips.
- **Thoughtful UX:** category colors flow through the app, categories can be archived without deleting history, and expenses support filters, sorting, amount ranges, note search, edit/delete, and note visibility.
- **Desktop delivery:** it is a real installable Tauri app, not only a webpage.
